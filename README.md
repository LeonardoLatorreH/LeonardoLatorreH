## Enfoque Profesional

- **Soporte TI y Help Desk Avanzado:** Diagnóstico de nivel de componentes, reparación de equipos, gestión de dispositivos mediante Active Directory/Intune, atención de tickets (Jira) y rescate de información crítica (GNU ddrescue, Clonezilla).
- **Redes, Infraestructura y Cloud:** Configuración de redes locales (VLANs, enrutamiento, DHCP/DNS), cortafuegos (pfSense), virtualización (Proxmox, VMware) y despliegue de entornos en la nube (AWS/Azure).
- **Ciberseguridad y Operaciones SOC:** Monitoreo y análisis de registros de eventos, detección de anomalías con Wazuh y Zeek, análisis de tráfico de red y aplicación de políticas de acceso seguro (MFA).
- **Automatización y Desarrollo Técnico:** Creación de scripts en PowerShell y Python para la automatización de tareas administrativas, despliegues con Docker/Ansible y gestión eficiente de bases de datos relacionales.
